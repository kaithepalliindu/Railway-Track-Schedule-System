# Railway Train Schedule System 🚆

## Description
A web-based application that displays railway train schedules and seat availability.
The system uses a Python backend with mock data to simulate real-time updates.

## Technologies Used
- HTML
- CSS
- JavaScript
- Python (Flask)

## Features
- View train schedules
- Seat availability display
- API-based architecture
- Easily extendable to real railway APIs

## How to Run
1. Install Python
2. Run:
   pip install -r requirements.txt
3. Start backend:
   python backend/app.py
4. Open frontend/index.html in browser
